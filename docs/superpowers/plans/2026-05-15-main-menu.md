# Plan de Implementación: Menú Principal — Freaky Super Mesh

> **Para agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans para implementar este plan tarea por tarea. Los pasos usan checkbox (`- [ ]`) para tracking.

**Goal:** Crear la pantalla de menú principal con personaje 3D animado, música de fondo, y botones de "Nuevo Juego" + "Salir" funcionales.

**Architecture:** Escena separada `MainMenu.unity` con Canvas en Screen Space - Overlay para UI 2D + cámara dedicada que renderiza al modelo 3D de Emilio a una RenderTexture mostrada como `RawImage`. Script `MainMenuController.cs` maneja todos los click events. Audio gestionado por un `AudioSource` 2D con fade-out al transicionar al gameplay.

**Tech Stack:** Unity 6.4 (URP), C#, TextMeshPro, Unity UI (uGUI), Animator.

**Notas previas:**
- Proyecto NO está en un repo git → en vez de `git commit` después de cada tarea, **guardá la escena con Ctrl+S** y considerá hacer un backup manual del proyecto al terminar cada tarea grande.
- Spec de referencia: [`docs/superpowers/specs/2026-05-15-main-menu-design.md`](../specs/2026-05-15-main-menu-design.md)

## Task 6: Crear el script MainMenuController

**Objetivo:** Lógica de los botones (Nuevo Juego con fade, Salir, Próximamente).

**Files:**
- Crear: `Assets/Scripts/UI/MainMenuController.cs`

- [ ] **Step 6.1: Crear el archivo del script**

En el Project window, click derecho en `Assets/Scripts/UI/` → `Create → MonoBehaviour Script`. Nombrarlo `MainMenuController`.

- [ ] **Step 6.2: Escribir el código del script**

Doble click sobre `MainMenuController.cs` para abrirlo en el editor (Visual Studio / Rider / VS Code). Reemplazar todo el contenido por:

```csharp
using System.Collections;
using UnityEngine;
using UnityEngine.SceneManagement;
using UnityEngine.EventSystems;

public class MainMenuController : MonoBehaviour
{
    [Header("Scene")]
    [SerializeField] private string gameSceneName = "Nivel01";

    [Header("Audio")]
    [SerializeField] private AudioSource bgmSource;
    [SerializeField] private float fadeDuration = 0.5f;

    [Header("UI SFX (opcional, se completa después)")]
    [SerializeField] private AudioSource sfxSource;
    [SerializeField] private AudioClip hoverSfx;
    [SerializeField] private AudioClip clickSfx;

    [Header("Selección inicial")]
    [SerializeField] private GameObject firstSelected;

    private bool isLoading = false;

    private void Start()
    {
        if (firstSelected != null && EventSystem.current != null)
        {
            EventSystem.current.SetSelectedGameObject(firstSelected);
        }
    }

    public void NuevoJuego()
    {
        if (isLoading) return;
        isLoading = true;
        PlayClick();
        StartCoroutine(FadeAndLoad());
    }

    public void Salir()
    {
        PlayClick();
#if UNITY_EDITOR
        UnityEditor.EditorApplication.isPlaying = false;
#else
        Application.Quit();
#endif
    }

    public void MostrarProximamente()
    {
        PlayClick();
        Debug.Log("Próximamente...");
    }

    public void PlayHover()
    {
        if (sfxSource != null && hoverSfx != null)
            sfxSource.PlayOneShot(hoverSfx);
    }

    private void PlayClick()
    {
        if (sfxSource != null && clickSfx != null)
            sfxSource.PlayOneShot(clickSfx);
    }

    private IEnumerator FadeAndLoad()
    {
        if (bgmSource != null)
        {
            float startVolume = bgmSource.volume;
            float t = 0f;
            while (t < fadeDuration)
            {
                t += Time.unscaledDeltaTime;
                bgmSource.volume = Mathf.Lerp(startVolume, 0f, t / fadeDuration);
                yield return null;
            }
            bgmSource.volume = 0f;
        }
        SceneManager.LoadScene(gameSceneName);
    }
}
```

Guardar el archivo (Ctrl+S en el editor de código).
